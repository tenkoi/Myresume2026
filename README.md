# Completed Online Resume — Teaching Example

Open index.html in a browser. Keep style.css and the images folder beside it.

All student details, qualifications and project descriptions are fictional examples. The email uses the example.com domain and is for demonstration. Project and portfolio links point to sections within this page so the example works offline.

## Compare with the starter
- HTML TODO 1–8: completed title, profile, education, skills, two project cards, contact and footer.
- CSS TODO A–J: completed heading styles, navigation, interaction feedback, section styling, Flexbox cards, links, footer and mobile rules.
- Additional Project Details section: working local destinations for portfolio links.
- Optional challenge: completed print stylesheet.

## Profile photo
The circular placeholder is intentionally retained. To use a real photo, save it as images/profile.jpg, change the img src in index.html and write suitable alt text.

## Classroom discussion
1. Which HTML elements organise the resume?
2. How does each navigation link match a section ID?
3. Which CSS declarations create the circular photo?
4. What do flex-wrap and flex: 1 1 250px do?
5. What changes at the 600px breakpoint?
6. How does :focus-visible support keyboard navigation?

Ask students to explain the code and personalise their own work rather than submit this example unchanged.
